# Institutional EA — Workspace Agent Rules

## Git & Repository Policy (Mandatory)

- **Remote Repository**: `https://github.com/gackstone/Institutional-EA.git` (`origin`, branch `main`)
- **Post-Task Auto-Push Rule**: Always stage, commit (with a clear, descriptive commit message), and push all project changes to `origin main` (`git push origin main`) immediately after completing any task or modification on this project.
- **Secret Protection**: Never stage or commit `.env`, credentials, API keys, or binary build/runtime artifacts excluded by `.gitignore`.
